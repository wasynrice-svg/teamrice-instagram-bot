# Images

Put the photos and videos for your posts in this folder, then list their file names in `posts.csv`.

- Photos must be **.jpg / .jpeg** (Instagram's API doesn't accept PNG). Up to 8 MB each.
- Videos (Reels) should be **.mp4**.
- Keep file names simple: lowercase, no spaces (e.g. `lake-house-front.jpg`).
- This repo is public, so anything in this folder can be seen by anyone with the link. Only add photos that are ready to go public.
